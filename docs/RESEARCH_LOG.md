# 2026-09-14 — M7 technical documentation check

The Central Square LOD1 export path was checked against current official documentation before implementation:

- Blender 5.x glTF exporter manual: <https://docs.blender.org/manual/en/5.0/addons/import_export/scene_gltf2.html>
- Blender Python export operator API: <https://docs.blender.org/api/main/bpy.ops.export_scene.html>
- Khronos glTF 2.0 specification: <https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html>
- Three.js `GLTFLoader`: <https://threejs.org/docs/pages/GLTFLoader.html>

Material decisions are limited to recognized Principled BSDF metallic/roughness inputs. No transparency or textures are used. Export applies evaluated mesh geometry, retains object extras for evidence metadata, and relies on the Blender exporter for Z-up to glTF Y-up conversion. GLB is treated as the runtime delivery artifact rather than the editable authoring source. No new architectural fact was introduced by this technical research.
