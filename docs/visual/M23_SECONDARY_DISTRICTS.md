# M23 — Secondary districts

Uptown Mall, One Uptown Residence, Parksuites, Market! Market! and three Serendra blocks have dedicated packages. Forbes Town, University Parkway and McKinley Parkway use named mapped corridors. Fourteen scored LOD1-Lite candidates receive type-based façade treatment with provenance and no invented architectural verification.

## Evidence and limits

Unavailable official pages remain marked as such in the manifest. Candidate uniqueness is not claimed. The existing seven approved LOD1 assets retain their original loading and Tour behavior.

## Reproduce

Run `scripts/m23/run.ps1 -Render` from the repository. Source geometry is in `scripts/m23/build.py`; runtime packages are in `web/public/world/detail/m23`; fixed cameras and hashes are in `data/reports/m23`. Generated Blender and GLB outputs can be recreated.

## Validation

See `data/reports/m23-validation.json`, `m23-performance.json`, `m23-reference-coverage.json` and `m23-visual-acceptance.json`. Static PASS does not grant appearance approval.
